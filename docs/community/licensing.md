# Publish knowledge you have the right to share

This unofficial community project is not affiliated with or endorsed by Render Cube, Toplitz Productions, Epic Games or UE4SS maintainers.

## Licensing boundaries

Original documentation prose is **CC BY 4.0**. Original code, inline code examples, scripts and configuration are **MIT**. Linked third-party resources retain their own terms; this project does not grant rights to game content or trademarks.

- [Documentation license terms](https://creativecommons.org/licenses/by/4.0/legalcode.en)
- [MIT terms](https://opensource.org/license/mit)
- Repository [license notices](https://github.com/rcarigna/medieval-dynasty-modding/blob/main/NOTICE.md)

## Allowed contributions

Original explanations, independently authored examples, curated links, and appropriately attributed observations of exposed interface names/relationships are welcome. Identify the source, revision and evidence status of game-specific claims.

A few interface names and a link to a historical declaration do not authorize copying its implementation, layout tables or bulk generated output.

## Excluded material

Do not contribute:

- decompiled/copied proprietary game implementations or reverse-engineered implementations;
- extracted audio, textures, models, animations or other game assets;
- game binaries or third-party tool DLLs;
- bulk generated game SDKs or memory dumps;
- private saves, personal machine paths, credentials or sensitive/raw logs;
- material copied from another project without appropriate permission and attribution.

Use upstream links instead of redistributing third-party content. If a contribution needs restricted material to be useful, open an explanatory issue with public-safe evidence rather than uploading it.

## Attribution and changes

Retain original attribution and license notices. Identify substantive changes when adapting documentation. Submit only material you can license under the project's stated terms. Maintainers may request removal/redaction or decline a contribution that cannot be shared safely and lawfully.
