# Contributing

Start with the [contribution guide](docs/community/contributing.md), [evidence standards](docs/community/evidence.md), and [content policy](docs/community/licensing.md).

Submit original material through ordinary Markdown pull requests. Include sources and verification metadata. Do not upload private saves, raw personal logs, proprietary implementations, extracted assets, binaries or generated SDK dumps.

Run `python scripts/validate.py`, `python -m mkdocs build --strict`, and `python scripts/validate.py --built` before submitting.
